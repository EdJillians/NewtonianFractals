# Newtonian Fractals

A Python project for computing and visualizing **Newton Fractals** (basins of attraction under the Newton-Raphson method in the complex plane) using NumPy, Matplotlib, and Pygame.

> [!NOTE]
> **Academic Context (Sep 2023 – Dec 2023)**  
> Developed during 6th form as a research project investigating fractal boundaries generated by numerical root-finding in the complex plane. The findings were documented in a scientific poster authored in LaTeX and presented to an audience of ~200 attendees at the **University of Exeter**.

---

## 🌌 Overview

A **Newton fractal** is a boundary in the complex plane characterized by applying Newton's method to find roots of a complex polynomial:

$$z_{k+1} = z_k - \frac{f(z_k)}{f'(z_k)}$$

Starting from each initial point $z_0 = x + iy$ on a grid, Newton's method is iterated until it converges to one of the roots of $f(z) = 0$. Each pixel is then colored according to the specific root it converges to. The boundaries between basins of attraction exhibit intricate, self-similar fractal geometry (Julia sets of the Newton map).

---

## ✨ Features

- **Arbitrary Complex Polynomials**: Solves roots for complex functions, such as roots of unity $f(z) = z^5 - 1$ or $f(z) = z^6 - 1$.
- **Automated Root Discovery**: Dynamically identifies unique roots within a numerical tolerance (`1e-8`) and assigns each an index.
- **Multiple Visualization Engines**:
  - **Matplotlib Renderer** (`MPLTFractal.py`): Clean scientific plots with automatic discrete or continuous colormaps (`ListedColormap`, `hsv`).
  - **Pygame Window** (`PygameFractal.py`): Interactive window with custom palette color mapping and automated export to `fractal.png`.
- **Modular Computation**: Clean separation between numerical root calculation (`calc.py`) and presentation layers.

## 📐 Mathematical Formulation

Newton's method iteratively refines an initial estimate $z_0$:

1. **Step Calculation**: $\Delta z = \frac{f(z)}{f'(z)}$
2. **Convergence Check**: if $|\Delta z| < 10^{-8}$, the root has converged.
3. **Update**: $z \leftarrow z - \Delta z$.
4. **Tolerance & Limit**: Terminate if convergence is not reached within `MAX_IT = 1000` steps or if $f'(z) = 0$.

Points in the complex plane that converge to the same limiting root form that root's **basin of attraction**.

## 🔍 Retrospective & Technical Insights

Reflecting on this project from a modern software engineering perspective, key areas for optimization and future iteration include:

- **Vectorized Computation**: The current solver iterates point-by-point through nested Python loops. Vectorizing the iteration over 2D NumPy arrays (`np.meshgrid`) or compiling via **Numba / Cython** would yield $50\times\text{--}100\times$ performance speedups.
- **Graphics Pipeline**: Rendering pixel-by-pixel with `screen.set_at()` can be transitioned to `pygame.surfarray.blit_array()` or GPU shaders for real-time zooming and panning.
- **Type Safety & Testing**: Adding Python type hints (`complex`, `np.ndarray`, `typing.Callable`) and automated unit tests for known roots of unity.
